# Finance Sales Dashboard – Power BI

## Project Overview

This project is an interactive Finance and Sales Dashboard
developed using Microsoft Power BI.

## Dashboard Features

- Total Sales
- Total Units Sold
- Sales by Segment
- Sales by Country
- Sales by Product
- Monthly Sales
- Profit by Segment

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization
- Data Modeling
